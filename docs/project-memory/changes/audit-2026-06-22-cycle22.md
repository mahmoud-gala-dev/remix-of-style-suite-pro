# Audit Cycle #22 — 2026-06-22 — Marketing Campaigns module

## Focus
أول موديول من قائمة "موديولات جديدة عالية القيمة" — حملات WhatsApp/Email/Push مجدولة مع segments.

## Schema
- `public.campaigns` (branch_id, name, channel, segment, subject?, body, scheduled_at, status, counters)
- `public.campaign_recipients` (campaign_id, customer_id, status, error, sent_at) UNIQUE(campaign,customer)
- RLS عبر `user_has_branch`، GRANTs لأدوار authenticated + service_role، فهارس على (branch,status) و(campaign,status).

## Server fns (`src/lib/campaigns.functions.ts`)
- `listCampaigns`, `createCampaign` (resolves segment → materializes recipients), `launchCampaign` (enqueues `campaign_message` jobs), `cancelCampaign`, `deleteCampaign`.
- Segments: `all` / `vip` (visits≥5 OR spend≥1000) / `inactive_30d` / `birthdays_this_month` / `custom`.

## Queue
- New kind `campaign_message` in `notification-queue.server.ts`.
- Drain handler dispatches per channel: WhatsApp via `sendWhatsappInternal`, Email via Resend connector gateway, Push via `broadcastWebPush`. Updates recipient + campaign counters; auto-marks campaign `sent`/`failed` when total reaches `recipient_count`.

## UI
- `/campaigns` route under `_authenticated/`, added to sidebar (management group, `Megaphone` icon).
- Form: name, channel, segment, optional subject, body (`{name}` placeholder), create-draft button.
- Table: status, counters, Launch / Cancel / Delete actions.

## Score impact
Adds a full marketing module reusing the cycle #16/#21 queue and Twilio/Resend wiring. No regression on existing flows.
