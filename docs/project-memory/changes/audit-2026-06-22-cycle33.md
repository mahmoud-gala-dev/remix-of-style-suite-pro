## Improvements Implemented
**P1 from Small-Business roadmap (#1 + #3 combined):**
- **3-step Onboarding Wizard** at `/onboarding`:
  1. **Branch** — name (EN/AR), address, phone, chairs (defaults to 09:00–22:00).
  2. **Pick a template** — Barbershop / Women's Salon / Unisex / Spa — seeds
     a starter service menu via existing `seedServiceTemplates` server fn
     (calls Postgres `seed_service_templates` RPC). Skippable.
  3. **First staff member** — name, phone, role, default 40% commission.
- **Auto-redirect CTA**: when the dashboard sees `branches.length === 0`,
  a banner appears at the top with "Start setup" linking to `/onboarding`.
- **Sidebar entry**: "Setup wizard" under the *management* group with the
  `Wand2` icon, so returning admins can re-launch it from anywhere.
