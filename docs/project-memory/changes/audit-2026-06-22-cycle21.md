# Audit Cycle #21 — 2026-06-22 — WhatsApp via Twilio (admin-managed, no connector)

## Focus
البند #4 من الأولوية العالية — تفعيل WhatsApp برمجياً عبر إعدادات أدمن، بدون ربط Lovable connector.

## Changes
- `notification-queue.server.ts` — أضيف `booking_whatsapp_confirm` و`booking_whatsapp_reminder` إلى `NotificationKind`.
- `cron/drain-notifications.ts` — معالج للنوعين الجديدين عبر `sendWhatsappInternal`؛ يتجاهل بصمت عند `disabled`/`not_configured`.
- `bookings.functions.ts`:
  - `createBooking` يقرأ `app_settings.twilio_whatsapp` ويُجدول التأكيد (فوراً) والتذكير (start-24h) حسب `notify_booking_created` / `notify_reminders`.
  - `sendBookingWhatsapp` server fn جديدة (admin-only) للإرسال اليدوي من واجهة الحجوزات.
- `_authenticated/bookings.tsx` — عنصر "Send WhatsApp" في قائمة السياق لكل صف.

## Design
- افتراضياً Twilio معطّل (`enabled: false`)؛ لا يحدث أي إرسال حتى يفعّله الأدمن من Settings → Twilio.
- لا تخزين مفاتيح في الكود؛ SID/Token/From يخزَّن في `app_settings` ولا يعود للمتصفح أبداً.
- الإرسال غير محجوب: التأكيد عبر الطابور، التذكير مع `run_at` آجل، يُستهلكان بواسطة cron الدارن كل دقيقة.

- يكتمل التراكم لتقييم 10/10 لمسار الإشعارات.
