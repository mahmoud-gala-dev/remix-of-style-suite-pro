# Audit Cycle #23 — Package Deals

Date: 2026-06-24

## Scope

Implements module #3 from the high-value backlog: pre-paid service packages
("10 sessions for the price of 8"). Adds backend schema, server functions, and
an admin UI to create/list packages and toggle their active state.

## Database

- `service_packages` — package definitions per branch (sessions_count, price,
  validity_days, optional service_ids[]).
- `customer_package_purchases` — per-customer purchases with
  `sessions_remaining`, `status` (active/exhausted/expired/cancelled), and
  `expires_at` derived from `validity_days`.
- `package_usages` — ledger of each consumed session, optionally linked to a
  booking and service.
- RLS scoped via `branch.tenant_id = ANY(public.current_user_tenants())`.
- Triggers: `set_updated_at` on packages and purchases.

## Server functions (`src/lib/packages.functions.ts`)

- `listPackages`, `createPackage`, `togglePackageActive`, `deletePackage`
- `sellPackage` — derives `expires_at` from `validity_days`, snapshots price.
- `listCustomerPurchases` — branch-scoped purchase list.
- `usePackageSession` — decrements remaining, marks `exhausted` at 0, refuses
  expired purchases (and back-fills `status='expired'`).

## Frontend

- `src/routes/_authenticated/packages.tsx` — create form + list with
  active toggle and delete.
- Sidebar entry under Finance (`src/lib/modules.ts`).
- i18n key `packages` (en/ar).
