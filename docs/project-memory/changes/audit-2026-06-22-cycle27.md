# Cycle #27 — Photo Gallery (encrypted)

- New tables: `service_photos`, `customer_photos` with tenant-scoped RLS.
- Private storage bucket `gallery` with tenant-scoped storage policies
  (`split_part(name,'/',1)::uuid = ANY(current_user_tenants())`).
- Path convention: `gallery/<tenant_id>/<service|customer>/<uuid>.<ext>`.
- Server fns in `src/lib/photos.functions.ts`:
  `createGalleryUploadUrl`, `recordServicePhoto`, `recordCustomerPhoto`,
  `listServicePhotos`, `listCustomerPhotos`, `deleteServicePhoto`, `deleteCustomerPhoto`.
  Reads return short-lived (1h) signed URLs via `createSignedUrls`.
- New route `/_authenticated/gallery.tsx` — upload (before/after/portfolio),
  caption, grid view with delete.
- `is_public` flag on `service_photos` reserved for future public booking page
  (`anon` SELECT policy already in place).
- Sidebar: "Photo Gallery" under management group; i18n keys added.
