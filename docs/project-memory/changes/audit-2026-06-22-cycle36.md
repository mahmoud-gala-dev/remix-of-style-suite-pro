## Improvements Implemented

### Approval workflows (`/approvals`)
- New `approval_requests` table (kind enum: discount / refund /
  cancel_paid_invoice / customer_delete / price_override / other,
  status enum: pending / approved / rejected / cancelled) with full
  tenant-scoped RLS (read = tenant members, insert = self in tenant,
  update = admin/super_admin in tenant only). GRANTs included.
- `src/lib/approvals.functions.ts` — `listApprovals`, `createApproval`,
  `resolveApproval` (admin-only via RLS).
- `src/routes/_authenticated/approvals.tsx` — status tabs + table +
  Approve/Reject buttons gated on `useRole().isAdmin`.

### Per-branch cost allocation (`/cost-allocation`)
- Client-only page using existing Zustand data. Computes per-branch
  platform spend (model: $5 baseline + $0.02/booking + $0.01/customer)
  + cost/revenue ratio, with bar chart + table.
- Color-coded ratio (green < 5%, amber < 15%, red ≥ 15%).

### Nightly Data Warehouse export cron
- New `/api/public/cron/warehouse-export` (cron-secret protected) —
  aggregates yesterday's bookings/invoices/new-customer facts per
  branch and emits one structured log line per branch
  (`warehouse.fact` event) for external ETL pickup (Metabase /
  Superset / BigQuery loader). No PII included.
